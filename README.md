# Aircraft Tracker

Приложение для отслеживания самолетов в воздушном пространстве разных стран с использованием открытых API.

## Описание проекта

Проект собирает данные о самолетах, находящихся в воздухе, с помощью API [OpenSky Network](https://opensky-network.org/) и сохраняет их в базу данных PostgreSQL. Для получения координат стран используется API [Nominatim](https://nominatim.openstreetmap.org/).

### Основной функционал:
- Получение данных о самолетах по 12 странам
- Сохранение информации в PostgreSQL
- Статистика по самолетам (средняя скорость, поиск по позывному)
- Автоматическое создание базы данных и таблиц

## Инструкции по установке и запуску

1) Для запуска проекта необходимо клонировать репозиторий, установить зависимости с помощью poetry и запустить скрипт main.py.
2) Установите зависимости через Poetry
```python
poetry install
```

3) Активируйте виртуальное окружение Poetry
```python
poetry shell
```

## Настройка базы данных
1) Убедитесь, что PostgreSQL установлен и запущен
2) Создайте файл database.ini на основе database.ini.example
3) Замените your_password на ваш пароль PostgreSQL

## Запуск

```python
python main.py
```

### Программа автоматически:

    Создаст базу данных aircraft_tracker (если её нет)

    Создаст таблицы countries и aeroplanes

    Соберет данные по 12 странам

    Сохранит данные в БД

    Покажет статистику

### Для всей функциональности проекта написаны тесты
Запустите тесты командой:
```python
pytest tests
```

## Методы DBManager
Метод	Описание
- get_countries_and_aeroplanes_count() -	Список стран и количество самолетов
- get_all_aeroplanes() -	Список всех самолетов в воздухе
- get_avg_speed() -	Средняя скорость самолетов
- get_aeroplanes_with_higher_speed() -	Самолеты со скоростью выше средней
- get_aeroplanes_with_keyword(keyword) -	Поиск по ключевому слову в позывном
